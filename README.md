# Game
## site-upgrade skill (use it in every project)

- **Claude Code, all projects:** `git clone` this repo, then `bash scripts/install-site-upgrade.sh` (copies to `~/.claude/skills/site-upgrade`; on Windows use Git Bash/WSL, or copy the folder `.claude/skills/site-upgrade` to `C:\Users\<you>\.claude\skills\`). Then use `/site-upgrade` anywhere.
- **Claude.ai / desktop app:** upload `dist/site-upgrade.zip` at Settings → Capabilities → Skills.
- **Single project:** copy `.claude/skills/site-upgrade/` into that repo.
